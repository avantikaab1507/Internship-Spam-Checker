# Internship Scam Checker

A student project that checks whether an internship offer — from **email, SMS,
WhatsApp, or a phone call** — is likely genuine or a scam.

It combines two detection layers:

1. **Rule-based red-flag engine** (`rules.py`) — a hand-written set of
   regex rules (fee requests, urgency language, requests for
   Aadhaar/bank details, "no interview needed" promises, WhatsApp-only
   contact, unrealistic pay, etc.), each with a severity score and a
   plain-English explanation. This is what powers the inline
   highlighting in the UI, and it's why the tool can *explain itself*
   instead of being a black box.
2. **Machine learning classifier** (`train_model.py` / `model/`) — a
   TF-IDF + Logistic Regression model trained on a labeled synthetic
   dataset of legitimate vs. scam internship messages
   (`data/internship_dataset.csv`), used as a secondary cross-check —
   useful when a scam message doesn't happen to match any hand-written
   pattern.

The two scores are combined (65% rules, 35% ML) into a single Risk
Score out of 100, with a verdict: **LIKELY GENUINE / SUSPICIOUS / HIGH
RISK**.

Because phone calls can't be analyzed as text automatically here, the
"Phone Call Checklist" tab gives a structured, interactive checklist
of the same red flags to walk through **during or right after** a
call.

## Setup

```bash
cd internship-scam-checker
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt

# (optional — a trained model is already included in model/,
#  but you can regenerate the dataset and retrain any time)
python3 data/generate_dataset.py
python3 train_model.py

python3 app.py
```

Then open **http://127.0.0.1:5000** in your browser.

## How the scoring works

- Each matched red-flag rule contributes `severity (1–5)` points.
- A few "positive signals" (named greeting, official-looking domain,
  explicit "no payment required") slightly reduce the score.
- The rule score is normalized to 0–100.
- The ML model separately outputs a scam probability (0–100).
- Combined score = `0.65 × rule_score + 0.35 × ml_score`.
- `< 35` → LIKELY GENUINE, `35–64` → SUSPICIOUS, `≥ 65` → HIGH RISK.

## Extending this project

Ideas if you want to take this further for your submission:

- **Improve the dataset**: replace/extend `internship_dataset.csv`
  with real (anonymized) examples of scam and legitimate internship
  messages for a more robust classifier.
- **Domain/URL checks**: add a rule that flags links using URL
  shorteners or domains that "typosquat" well-known companies
  (e.g. `tcs-careers-online.com` instead of `tcs.com`).
- **Browser extension**: wrap the same `/analyze` API into a Chrome
  extension that scans Gmail/WhatsApp Web messages in place.
- **Speech-to-text for calls**: integrate a speech-to-text API so a
  recorded call (with consent) can be transcribed and run through the
  same `analyze_text()` pipeline instead of the manual checklist.
- **Feedback loop**: let users mark a verdict as wrong, and use that
  to retrain/improve the model over time.

## Disclaimer

This is a decision-support tool, not a guarantee. Always verify an
internship offer independently through a company's official website
or verified HR contact before sharing personal information or paying
any money.
